Microsoft.Windows.Console.ConPTY
================================

Copyright (c) Microsoft Corporation.

The Windows app ships the pane holder's ConPTY runtime (conpty.dll and
OpenConsole.exe) in holder-conpty/, unchanged, from Microsoft's NuGet package
Microsoft.Windows.Console.ConPTY 1.24.260710001
(https://www.nuget.org/packages/Microsoft.Windows.Console.ConPTY,
https://github.com/microsoft/terminal). The package and each file are
verified at build time against the version and sha256 digests
contracts/conpty.json records, and the holder checks each file's digest
again before it loads the runtime.
