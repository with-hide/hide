Practice is a window built into hide where you learn the screen by doing the moves.
It runs on the real sidebar, panes and keyboard of hide, drawn over a scripted world.
No real agent, project or file is touched, so you can try anything.

## Open it

- Open the **Help** menu with the `?` button at the bottom of the sidebar, then choose **Practice Hide**.
- On the first launch, choose **Try it on a practice screen first** in the last setup step, **How do you want to start?**
- With no project added, the Home has the same **Try it on a practice screen first** line.
- Until you open a flow or close it, the sidebar shows a **Practice Hide** row, **Start with handing over a mission**. Its × closes the row for good, and Help keeps the entry.

Opening practice from Help shows the list of flows.
The setup step and the sidebar row open it on the mission flow.
In the desktop app, practice opens in a window of its own beside the main window; asking again brings the open one forward.
**Back to Hide** always closes it.

## What you learn

Practice is a list of five flows. Pick only the ones you need.

| Flow | What you do in it |
| --- | --- |
| 1. At a glance | See the three parts of the screen and what each is for, and search to find anything. |
| 2. Run several agents | Start another agent beside the first or by words, answer what waits on you first, look at what an agent opened, go back and forth, and close and reopen. |
| 3. Hand over a mission | Hand a Conductor (the agent that plans a job and starts workers for its parts) a job of six parts, approve its plan, see the workers it starts, answer the one question it brings to Needs You, and find what was decided in Memory. |
| 4. Find and look again | Session search, a session's record, a pull request's card, and Revisit. |
| 5. The project at a glance | The right lane: counts, the last 7 days, Explorer and Hide AI. |

A guide dims everything but the part a step is about, rings it, and says what to do and which keys do it.
Press Enter and the guide does the step for you; press the keys yourself and it moves on as soon as you finish.
Every step after the first has **Back**, and the bubble's lower left has **Exit**.

Keys in practice are your own: the ones your system uses, and any you set in Settings.
Practice remembers which flows you have seen while a hide window is open.

## When to use it

Use it before your first real task if you want to see a mission, a question in Needs You and the PR card without risking a repository.
Then go to [First 10 minutes](/docs/start/first-10-minutes/) to do the same on your own project.
