Questions

Before you install.

Is hide free?

Yes. The app, every agent, every device, the core and the phone are free and Apache 2.0 licensed. The Software Factory will be a paid plan when it opens.

How is this different from running agents in a terminal?

You still run them in a terminal: each agent is its own CLI in a real Herdr pane, started the way you start it today. hide adds what one terminal cannot: agents that start, watch and write to each other, one list of what needs you across every machine, the titles Hide AI writes, and Project Memory the next agent starts with.

Is hide a wrapper around my agent?

No. hide adds its hooks to each agent's own settings and a skill the agent can call, and the vendor's CLI runs as it does without hide. Your subscription, config, skills and MCP servers stay as they are.

Which agents work with it?

Claude Code, Codex, Antigravity, OpenCode, Grok, Pi and omp, each with its own login. Every one gets the same status, title and place to answer. Grok takes letters only while it works and does not use Project Memory yet.

I already use Herdr.

hide is built on Herdr and opens on top of your running Herdr server as it is. Your workspaces, panes and agents are there on first launch, and nothing is stopped or replaced. No Herdr yet? hide brings its own.

Does my code leave my machines?

Not through hide, which has no hosted service. Agents, the core and Hide AI run on machines you own, with the agent CLIs you already signed in to, so code goes only where those CLIs send it. Your phone reaches your machines over your own Tailscale.

Do I need a second machine?

No. Everything runs on one laptop. An always-on Mac lets your agents keep working while the laptop sleeps.

How do I reach you?

Email hello@withhide.dev for questions, the Factory list, Enterprise and teams. Bugs and feature requests go to GitHub issues ↗.
