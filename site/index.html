How hide helps

Three things hide does so you can hold less.

Agents start, watch and write to each other.

A lead starts workers, a worker starts a helper, on this machine or another. The agent that started a child watches it, and they write to each other in letters. Mix vendors freely: one writes, another checks. The tree shows who started whom.

  • A child runs in its own tab and reports to its parent, not to you.
  • A parent hears within a minute when its child stops on a question, and after 20 quiet minutes when it stalls.
  • Claude Code and Codex can end a turn and wait: the letter they wait for wakes them.
  • A letter reaches a working agent within five minutes, or at its next step when it cannot wait.

Only what needs you comes up.

Hide AI reads what each agent did and gives it a title and a one-line summary. Agents sort themselves into four groups, and the ones waiting on you sit on top on every screen.

  • Needs You, Unread, Working, Seen. Nothing else to watch.
  • Each task keeps a record: what it is doing now, and what you asked, ticked off.
  • Runs on the agent CLI you already signed in to. No new API key.

One core. Any screen.

Put hide's core on the machine that never sleeps. Projects, letters, titles and the Factory live there. Your laptop becomes a screen: close it and nothing stops. Your phone answers the one that needs you.

  • Add any machine by its SSH alias. Its agents join the same groups.
  • Everything runs on machines you own. Free, not a hosted plan.

Still an IDE

The terminal stays in front.

Agents live in real terminals. What they point at opens beside them, and goes away when you are done.

  1. Open a pathThe file opens beside the agent that named it.
  2. Read the diffEach checkout's changes, one click from its tab.
  3. Check the pageA built-in browser your agents can drive too.

Around the agents

Nothing to keep in your head.

What sessions decided, what is left to start and which pull request waits on you are kept where you will look.

Questions

Before you install.

Is hide free?

Yes. The app, every agent, every device, the core and the phone are free and Apache 2.0 licensed. The Software Factory will be a paid plan when it opens.

Which agents work with it?

Claude Code, Codex, Antigravity, OpenCode, Cursor, Grok, Pi and omp, each with its own login. Every one gets the same status, title and place to answer. Grok and Cursor take letters only while they work and do not use Project Memory yet.

I already use Herdr.

hide is built on Herdr and opens on top of your running Herdr server as it is. Your workspaces, panes and agents are there on first launch, and nothing is stopped or replaced. No Herdr yet? hide brings its own.

Does my code leave my machines?

Not through hide, which has no hosted service. Agents, the core and Hide AI run on machines you own, with the agent CLIs you already signed in to, so code goes only where those CLIs send it. Your phone reaches your machines over your own Tailscale.

Do I need a second machine?

No. Everything runs on one laptop. An always-on Mac lets your agents keep working while the laptop sleeps.

How do I reach you?

Email hello@withhide.dev for questions, the Factory list, Enterprise and teams. Bugs and feature requests go to GitHub issues ↗.
