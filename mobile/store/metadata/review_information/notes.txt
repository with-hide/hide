Hide for iPhone is the phone side of Hide, a free desktop program that people run on their own Mac, Windows or Linux computer (withhide.dev). The app has no account and no sign-in, so there is no demo account. It has a built-in demo with sample data instead. The demo opens every screen of the app and shows the app's full feature set, and we ask that it be the way this app is reviewed (guideline 2.1(a)).

HOW TO TRY THE APP WITHOUT A COMPUTER
1. Open the app. On the first screen tap "Try the demo" (the Korean interface says "체험해 보기").
2. A slim bar, "Demo - sample data", stays on top of every screen. Nothing is sent or saved in the demo.
3. Agents tab: the sample computer's agents, grouped Needs You, Working, Unread and Seen. Open one to read its conversation and type a reply: the demo answers with a sample reply. The start button adds a sample agent.
4. Missions tab: a mission with its steps, a pull request per step and one decision waiting. Tap an option to answer it.
5. PRs tab: sample pull requests with status and reviews. "Merge" takes one off the list and "Assign" hands one to a sample agent.
6. Open the first agent and its "To look at" tab: one page made by an agent ("Install guide") and one image, shown in the app.
7. Settings tab: language, and Notifications. Turn the Notifications switch on and allow notifications when iOS asks. About 2 seconds later a sample notification arrives: "Needs You - Apply all 3 review comments?", with a Reply action. Lock the phone before it arrives to see it on the lock screen.
8. "Leave demo" (top bar) returns to the first screen. "Connect my computer" opens the QR scanner (camera permission), which needs a real computer running Hide.

WHY THIS IS MORE THAN A WEB PAGE (4.2)
- Encrypted push notifications: Apple's push carries an encrypted body that a notification service extension in the app decrypts on the device, so neither Apple nor our relay sees the text.
- Reply from the notification: the notification has a Reply action that needs the phone to be unlocked (Face ID or passcode) before it runs, and sends the reply end-to-end encrypted to the user's computer.
- Pairing keys are kept in the iOS Keychain.
- A native QR scanner pairs the phone with a computer.
- Universal links (app.withhide.dev) open a pairing link or a notification's agent in the app.

4.2.3 AND 4.2.7
The phone is not a screen mirror and no code runs on it. The computer runs Hide and the agents; the phone shows agents, conversations, missions, pull requests and results in its own native-hosted interface and sends the user's typed input back. The connection goes through a relay and is end-to-end encrypted (Noise), and there is no account. Hide on the computer is free and is downloaded by the user from withhide.dev.

"TO LOOK AT" (agent-made HTML)
The "To look at" tab can show a page that the user's own agent made on the user's own computer, drawn in a sandboxed frame with a content security policy. It is the user's own content from the user's own computer, not third-party software, and it does not change the app's features (2.5.2; 4.7 does not apply).

THE STORE SCREENSHOTS

ENCRYPTION
The app uses only standard encryption algorithms (Noise_NK with X25519, ChaCha20-Poly1305 and BLAKE2b for the connection; Ed25519 signatures; RFC 8291 Web Push encryption with P-256 and AES-128-GCM and HMAC-SHA-256 for notifications) for its own connection and notifications, so it qualifies for the exemption.
